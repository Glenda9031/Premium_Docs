# Section Intro

In this section, we will learn all about CSS Grid, which is another layout model that is similar to flexbox but it is two dimensional instead of one. You can use the grid for simple stuff like a 3 column card layout but you can also use it to create complex layouts where specific elements can span a number of rows and columns.
