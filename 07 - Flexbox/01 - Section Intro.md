# Section Intro

In this section, we will learn a very important part of CSS called Flexbox. Flexbox is a layout model that allows you to design complex layouts with a lot of flexibility. It is very useful for creating responsive designs and it is supported by all modern browsers. Right now, we know how to add basic styles, but we have not gone over any way to layout elements and create rows and columns. Flexbox will allow us to do that.

Back in the day, we used to use floats to create layouts. This was not ideal because it was not very flexible and it was hard to align elements correctly. Flexbox makes it very easy to center elements both horizontally and vertically. It also makes it easy to create rows and columns. I don't even remember the last time I used floats for layout and I don't teach them because they are outdated and I can't think of a good reason to use them.
