# Section Intro

In this section we will look at some new ways to select elements from a web page. We know how to use elements, classes and IDs, but there are more advanced ways to get let's say all of the even li tags or the 3rd div in a container. We can do this with something called `pseudo selectors`.

Here are the lessons in this section:

1. Attribute Selectors
2. Child & Sibling Combinators
3. Pseudo Elements
4. first-child, last-child & nth-child Pseudo Classes
5. first-of-type, last-of-type and nth-of-type Pseudo Classes
6. ::before & :: after Pseudo Elements
7. Image Overlay Mini-Project
8. has(), is() & where() Pseudo Classes
9. Styling Forms
10. Selectors Challenge
