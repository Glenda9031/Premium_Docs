# CSS Basics

Now we get to the fun part, which is CSS. Well I would say the real fun part is the projects, but we need to learn the basics first. In this section, we will learn about the syntax of CSS, how to apply CSS to HTML, and how to style elements on a webpage. We'll look at the different way to select elements from our HTML. We'll look at different properties for things like colors, text, and backgrounds. We'll talk about CSS specificity, which relates to the rules of which selectors apply to elements when multiple CSS rules target the same element. These are the absolute fundamentals of CSS. Once we learn this, we can start to get into the box model, flexbox, css grid and responsive design.
