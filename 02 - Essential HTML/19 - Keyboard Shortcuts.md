# Editor Shortcuts

I know that this is not specifically related to HTML and CSS, but I want to help you guys get a good start with your code editor. I think it's important to be efficient with your editor because it can save you a lot of time and make you more productive. I'm going to show you some shortcuts that I use in Visual Studio Code, but most editors have similar shortcuts.

## Command Palette

The command palette is a great way to access all the commands in Visual Studio Code. You can open it by pressing `Ctrl + Shift + P` or `Cmd + Shift + P` on a Mac. You can then type in a command and it will show you all the available commands that match what you typed. This is a great way to quickly access commands without having to remember all the shortcuts.

## UI Shortcuts

- **Ctrl + P**: Command Palette
- **Ctrl + B**: Toggle sidebar
- **Ctrl + J**: Toggle panel/terminal
- **Ctrl + Shift + E**: Show Explorer
- **Ctrl + Shift + F**: Search in files
- **Ctrl + Tab**: Switch between open files
- **Ctrl + Shift + Tab**: Switch to the previous open file

## General Shortcuts

Here are some general shortcuts that you can use in most editors:

Note: For Mac users, replace `Ctrl` with `Cmd`.

- **Ctrl + S**: Save
- **Ctrl + Z**: Undo
- **Ctrl + Y**: Redo
- **Ctrl + C**: Copy
- **Ctrl + X**: Cut
- **Ctrl + V**: Paste
- **Ctrl + F**: Find
- **Ctrl + H**: Replace
- **Ctrl + A**: Select All
- **Ctrl + Shift + Z**: Redo
- **Ctrl + Shift + T**: Reopen Closed Tab
- **Ctrl + Shift + N**: New Folder

## Productivity Shortcuts

Here are some productivity shortcuts that you can use to speed up your workflow:

Note: For Mac users, replace `Ctrl` with `Cmd`.

- **Ctrl + Arrow**: Move to the beginning or end of a word
- **Ctrl + Shift + Arrow**: Select text
- **Alt/Option + Arrow Up/Down**: Move a line up or down
- **Shift + Alt/Option + Arrow Up/Down**: Copy a line up or down
- **Ctrl + /**: Comment out a line
- **Ctrl + D**: Select the next occurrence of the selected text
- **Ctrl + Shift + L**: Select all occurrences of the selected text
- **Ctrl + Enter**: Insert a new line below the current line
- **Ctrl + Shift + Enter**: Insert a new line above the current line
- **Ctrl + W**: Select current element and everything inside of it
- **Ctrl + Shift + W**: Select everything inside the current element

There are more, but these are the ones that I commonly use. I suggest practicing these. It will make you more efficient and productive in your coding.
