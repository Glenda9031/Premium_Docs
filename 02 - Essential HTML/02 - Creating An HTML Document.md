## Creating An HTML Document

To create an HTML document, you can use any text editor. I recommend using Visual Studio Code, but you can use any text editor you are comfortable with. Here are the steps to create an HTML document:

1. Open your text editor.
2. Create a new file and save it as `index.html`. You can save it anywhere on your computer for now.
3. Add the following to the file:

```html
<h1>Hello World!</h1>
```

Don't worry about the code for now. We will cover it in soon. For now, I just want to show you how to create and open an HTML document.

4. Save the file.

Now, from your file explorer, open that file with your browser. If you double-click the file, that should work unless your OS is set up to open HTML files with a text editor. If that's the case, you can right-click the file and select "Open with" and choose your browser. You can also drag the file into the browser or open the browser and select "Open file" from the menu. Any of these methods will work.

When you open the file, you should see the text "Hello, World!" displayed in the browser. This is the most basic HTML document you can create.

There are a few things that I want to mention.

First, the `.html` extension tells the browser that this is an HTML file. This is important because the browser needs to know how to interpret the file.

Second, the name `index.html` is a common name for the main page or the "homepage" of a website. When you visit a website, you are usually taken to the `index.html` file. You can name the file anything you want, but `index.html` is a common convention.

Lastly, we aren't running this file on a server. We are just opening the file in the browser locally. This is why you can see the file path in the browser's address bar. If you were to run this file on a server, you would see the domain name instead of the file path. This is not accessible to anyone else, it is local to your machine.

When you build a website and you're ready to make it live, you can purchase a web hosting account or use a free hosting service and upload your files to the server.

You can also use a local server to run the file, which is what we'll be setting up in the next video.
