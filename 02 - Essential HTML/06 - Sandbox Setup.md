# Sandbox Setup

In many of my courses, I like to create what I call a "sandbox". This is just a folder with files that go along with the course. It's a place where you can practice and experiment with the code. One of the main reasons I do this is because it serves as a reference for you to look back on and easily find the code from a specific lesson. The sandbox is for non-project lessons. When we build a project like a landing page, it will have it's own folder and files.

This is not mandatory for the course. If you would like to just follow along with the videos and create your own files, that is perfectly fine. I just think it's a good idea to have a place where you can practice and experiment with the code.

## Starter & Finished Code

In the downloads for this lesson, there will be two folders. One is the starter code (`html-css-sandbox-starter`) and the other is the finished code (`html-css-sandbox-finished`). The starter code is what you will start with. The finished code is what you will end up with after following the lesson. In some cases there may be some pre-written code in the starter code. This is just to save time and to keep the lesson focused on the main topic.

Not every lesson or section will have a sandbox folder/file. Some lessons are just informational. Also, the larger projects, will have their own folders.

## Folder Structure

The structure is simple. We will have a folder for each section and lesson. For example the first folder is called `01-getting-started-with-html/01-document-structure`. Inside the folder, we have an `index.html` file. The numbers of the sandbox folder do not necessarily correspond to the lesson numbers. They are just there to keep things organized. If there are any images or stylesheets needed, they will be in the same folder as the `index.html` file.

## Getting Setup

There are a few ways to do this course. You can download the files and extract them to a folder on your computer and rename the `html-css-sandbox-starter` folder to `html-css-sandbox` and open that folder in VS Code or whatever you are using and use those files. You can also create the folder yourself and create the files manually if you'd like. Then if there is any starter code, you can copy and paste that into your files.

## Start Up Live Server

Open the first HTML file in your editor, which is `01-getting-started-with-html/index.html` and select `Open with Live Server`. This will open the file in the browser. You can also just create your own HTML file and open that. Now you are ready to start coding.
