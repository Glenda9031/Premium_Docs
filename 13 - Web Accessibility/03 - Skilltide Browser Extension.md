# Skilltide Browser Extension

Skilltide is a browser extension that helps you to understand the accessibility of your web pages. It is a tool that can be used to check the accessibility of your web pages and to help you to understand how to make them more accessible. It has a built-in screen reader, so you can experience your website using a screen reader.

Let's install this extension so that we can use it to learn more about accessibility.

Go to https://silktide.com/toolbar/ and install the extension.

I believe this extension is only available for Google Chrome. So you will need to install and use Chrome to use this. However, if you want to use Firefox, another similar extension is available at https://addons.mozilla.org/en-US/firefox/addon/wave-accessibility-tool/

Once you install it, you should be able to click on the icon and open the sidebar.

Let's just browse over some of the features:

- Accessibility Checker: This is a tool that will check your website for accessibility issues. It will give you a list of issues that you can fix to make your website more accessible.
- Color Contrast: This will check your website for color contrast issues. It will tell you if your colors are too close to each other and if you need to change them.
- Alt Text: This will check your website for images that do not have alt text. It will give you a list of images that need alt text.
- Screen Reader: This is a built-in screen reader that will read your website out loud. This is useful for testing your website for accessibility and seeing or rather hearing what it is saying.
- Focus Order: This will show you the order of focus when hitting tab on your keyboard. This is useful for testing your website for accessibility and seeing how the focus order is.
- Landmarks: This tool shows and outlines the semantic areas of your website.
- Headings: This tool will show all of the headings on your web page. This is useful for testing your website for accessibility and seeing if your headings are in the correct order.
- Impaired Vision: This will show you what your site looks like with different levels of impaired vision.
- Color Blindness: This will show you what your site looks like with different types of color blindness.
- Dislexia: This will show you what your site looks like with dislexia.

As you can see, this is a really in-depth tool that helps you make your projects much more accessible.
