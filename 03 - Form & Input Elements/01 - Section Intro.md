# Section Intro

In this section, we will learn about HTML forms and inputs. Forms are an essential part of web development and are used to collect data from users. Forms can be used for things like login pages, contact forms, and surveys. HTML is not used to process the data, but it is used to create the structure of the form. The data is typically sent to a server for processing using a server-side language like PHP, Python, or Ruby or you can use JavaScript to handle the form data on the client-side.

We will look at a bunch of different inputs such as text, password, email, radio buttons, checkboxes, and more.
