# Welcome To The Course

Hello and welcome to Modern HTML & CSS From The Beginning 2.0. This course was first created back in 2017 or so and even though 99% of the old version is still relevant today, I decided to do a complete overhaul because to me, this is my most important course. It's the starting point for everything else and for many people, it will be the first course of mine that they take. There's nothing in this version of the course that was in the older version. I've recreated the entire thing from scratch with more information, cleaner practices and better projects.

HTML & CSS are the building blocks of the web. Try and imagine what the web would be without these two technologies. You really can't. It would be a bunch json files. If you don't know what that is, don't worry about it. In this course, we start by learning all of the fundamental HTML tags and attributes as well as exploring things Emmet and keyboard shortcuts for productivity. It is an HTML and CSS course, but let's be honest, HTML is simple compared to CSS. I know senior developers that still struggle to center a div. We'll cover everything from basic properties like color and font-size to the box model, flexbox, css grid, pseudo classes, specificity, animation, responsive design and so much more. We'll even be learning about version control with Git as well as deploying to multiple hosting services including Netlify and Vercel.

This course includes a few different kinds of sections. There are learning modules where we work in a sandbox environment to learn different elements, CSS properties and other concepts. Then there's a bunch of mini-projects and challenges which are mostly geared toward learning a specific thing. Then there's 3 actual website projects where we take everything that we learned previously and put it together. There will also be a 4th project added in the near future that includes using the Sass CSS pre-processor.

This course is for people that are at all kinds of skill levels. Of course, it's for beginners. If you're just starting out, you should go through all of the videos beginning to end. If you already know the fundamentals then you can skip around and just do the modules where you may be struggling a bit and then go straight to the projects.

As far as the websites we'll be building, the first one is for a design or photography agency called Lumina Creative. It's a responsive and minimalistic website with a homepage, about page and contact page. We'll be using the flexbox layout model. We'll also be pushing this website to GitHub and deploying it to Netlify. We'll also hook up the contact form using Netlify's form services. This is all free as well. We'll also hook up a domain name from Namecheap. I want to you understand the whole process from start to finish.

The second project is a website called Tutor and it's a site for a course that teaches you how to create courses. This will be much more CSS heavy. We'll also be using a bit of JavaScript for things like the hamburger menu and adding a background to the navigation bar on scroll. Of course, it will be fully responsive and will use both flexbox and CSS Grid for layout. We'll deply this project to Vercel and use a service called Formspree for the contact page.

The Third project is a website for a mobile app called Leno. It's a fictional health and productivity app. In this project we're going to use a CSS methodology called BEM, which stands for block element modifier. This isn't any kind of library or technology. It's just a convention on how we name our classes and structure our content. It will have the same type of responsive navbar with a mobile menu. We'll create an animated button with CSS and also create a modal with CSS and a little bit of vanilla JavaScript. This isn't a JavaScript course and we're not going to be doing anything really difficult, so don't let that overwhelm you.

In addition to the main projects, we'll have mini-projects like a landing form, a pricing grid, cards for a clothing collection, an animated CSS loader and a bunch of others.

I'm really proud of this course and I think you'll learn a ton even if you already know the basics. In the next video, we'll talk a little bit about how the web works before we get started.
