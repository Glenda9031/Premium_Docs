# Premium Docs

Everyone that purchases this course through traversymedia.com gets  the premium documents, which is basically a written version of the course. There is a folder for every section and lesson with markdown files along with the code samples that we write in that particular lesson.

There will be a download link on this page to download the docs. I would suggest that you uncompress the zip file and open the folder in a VS Code editor window so that you have all of the files and folders in your sidebar explorer. You can then view the markdown either with the default Markdown viewer by right clicking the file in the sidebar and selecting 'Open Preview' or you can install an extension like "Markdown Preview Enhanced", which has a few more features. This is what I like to use.

Hopefully you guys find these useful.
