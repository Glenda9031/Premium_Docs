# Where To Go From Here

Congrats on completing the course! This was a pretty long one. I want to thank you for purchasing and taking the course. You now know the fundamentals of HTML and CSS and you'll use what you've learned throughout your entire career. Now, let's talk about where to go from here.

As far as skills go, every front-end and/or full-stack web developer needs to know HTML/CSS. If your main goal is to get a job as a dev at a company, then I would suggest moving on to JavaScript. Yes, you can apply to certain positions, like an HTML email developer, however, most jobs are going to want you to know JavaScript. 

Another option that you have right now is to jump into a CSS framework such as Tailwind CSS or Bootstrap. These make building websites and interfaces easier as you have pre-defined classes to use. Tailwind is much more customizable because it is a utility-based framework where you have a class for just about every element. However, Bootstrap is a lot more batteries-included and has pre-build components including JavaScript widgets. So it's up to you on which you want to learn. 

If becoming a freelance developer is your goal, it's not impossible to start up and try to get some clients. It depends what on the types of projects. You can specialize in brochure-type websites for small businesses and individuals. This wouldn't be my reccomendation yet, but it is possible. In fact, when I started freelancing I didn't know much more than HTML, CSS and some Wordpress, which is also an option that you can move on to. Wordpress is a lot of work in a graphical user interface, so you don't even need to write code to create some cool stuff. You will be limited though with no knowledge of PHP and JavaScript.

So you have quite a few choices on where to go from here.
